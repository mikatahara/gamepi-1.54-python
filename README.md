# gamepi-1.54-python
Python tools for hacking the Spotpear GamePi 1.54 on Raspberry Pi Zero 2 W, including LCD and GPIO control.

## gamepi_lcd.py
GamePi 1.54 / ST7789V 240x240 LCD driver for Raspberry Pi Zero 2 W + Ubuntu/Linux.

- test_box.py<br>
Draw the boxes arranged side by side.

- test_dot.py<br>
Fill in line by line

- test_line.py<br>
Fill in row by row, then clear the grid 
 and fill in column by column.
